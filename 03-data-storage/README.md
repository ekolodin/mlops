## Что разберём

Как хранить данные при отказах дисков и серверов: RAID, репликация и
избыточное кодирование. Сжатие без потерь; хранение и распределённая обработка
таблиц в YTsaurus; объекты и бакеты S3, доступ, жизненный цикл и версии объектов.

Версионирование данных в DVC: указатели, кэш и remote.
Передача данных через `dvc push` и `dvc pull`, восстановление предыдущей версии.
Отличия DVC от Git LFS.

## Практика

Обучим CatBoost на двух версиях обучающей выборки Titanic и сравним качество
на неизменной тестовой выборке. Сохраним данные через DVC, отметим версии
Git-тегами, затем восстановим первую версию и повторим обучение.

Для подготовки нужны Python 3.13, uv и Git.
Команды установки и выполнения — в [README практики](practice/README.md#подготовка).
