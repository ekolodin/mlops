# Промышленная разработка ML

Курс для студентов старших курсов о том, как превратить ML-эксперимент в
проверяемую, воспроизводимую и работающую систему. Учимся организовывать код
и зависимости, управлять данными и экспериментами, тестировать модели,
автоматизировать процессы и передавать результат в эксплуатацию.

Программа также охватывает мониторинг, масштабирование, оптимизацию на NVIDIA GPU,
ONNX, TensorRT, Triton Inference Server и интеграцию ML с приложениями.
Теория закрепляется практикой на коде и данных. Предполагается знакомство с
Python, Git и основами машинного обучения.
